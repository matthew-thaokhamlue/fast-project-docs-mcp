# Security Policy

This policy covers the Document Generator MCP server in this repository.

## Supported Versions

The project has no numbered releases. The `main` branch is the only supported version. A security fix is merged to `main`.

## Reporting a Vulnerability

Report a vulnerability through GitHub's private vulnerability reporting:

1. Open the **Security and quality** tab of this repository.
2. Select **Report a vulnerability**.
3. Fill in the form and submit it.

The form is also at https://github.com/matthew-thaokhamlue/fast-project-docs-mcp/security/advisories/new. GitHub notifies the repository owner, and the report stays private.

Keep the details out of public issues and pull requests until the fix is merged.

A report includes:

- the tool, file or function affected
- the steps that reproduce the problem
- what an attacker can read or change

### What happens to a report

1. The repository owner replies on the report within 5 working days.
2. Accepted report: the fix is merged to `main`, and the owner tells the reporter.
3. Declined report: the owner closes the report and gives the reason.
